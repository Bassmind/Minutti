#Minutti
Este es un proyecto sencillo en Kotlin para una aplicación que permita generar presupuestos basados en opciones elegidas por el usuario.
Tendrá los siguientes modulos:
- Módulo para administrar y añadir/eliminar productos junto con su precio.
- Módulo para hacer un presupuesto, donde se enlistarán los elementos posibles a añadir junto con su precio, y al elegirlos se mostrará un popup para elegir el número.
Al haber elegido los elementos deseados, se mostrará el resumen final donde se podrán editar el número de elementos seleccionados o borrar/añadir alguno más, y dar un presupuesto final.
- En el módulo de presupuestos, habrá un elemento especial que es diferente a los demás y tiene varias variantes, el cual tendrá una interfaz especial

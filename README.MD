#Minutti
Este es un proyecto sencillo en React para una aplicación que permita generar presupuestos basados en opciones elegidas por el usuario.
Tendrá los siguientes modulos:
- Módulo para añadir/eliminar productos junto con su precio.
Adicionalmente, habrá un producto especial llamado Globo que tiene más propiedades.
- Módulo para hacer un presupuesto, donde se enlistarán los elementos existentes junto a un check box para que el usuario añada cuantos elementos quiere.
Al haber elegido los elementos deseados y dar click en siguiente, se mostrará el resumen final donde se podrán editar el número de elementos seleccionados o borrar/añadir alguno más, y dar un presupuesto final.
